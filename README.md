# CreatorKit

An all-in-one content creation platform for YouTubers, gamers, streamers, and digital creators.

- Persian and English support
- Creator tools for titles, descriptions, hashtags, ideas, hooks, scripts, and content planning
- Free-first project with a cinematic purple-and-cyan design

## Project status

The web app is being prepared for GitHub Pages. Authentication, cloud storage, AI-provider integration, and payments require separate secure service configuration before they can be considered live.
